指标口径与数据来源

上下文取 Codex 最近快照除以有效窗口；压缩后的快照与最近真实请求用量分别保存。压缩前后大小是相邻已记录快照，未完成的压缩后数据不猜测。缓存输入属于输入子集；缓存输入占比 = 所选统计范围内的缓存输入 Token ÷ 输入 Token，输入为零或缺失时显示 —；推理 Token 单列，是否计入输出取决于网关口径，面板不重复相加。TTFT 读取最近 task_complete 的 time_to_first_token_ms。TPS 使用同一轮累计 output_tokens 除以 duration_ms（秒）；没有 duration_ms 时使用该轮起止时间差。此值衡量整轮平均吞吐，包含模型请求、工具执行及等待，与纯模型生成速度口径不同。工具耗时按已记录条目的起止区间合并，避免并行重复累计；缺少计时的条目不按零时长计算。近 10 轮 TTFT 展示有效样本均值、中位数，TPS 取有效轮次总输出除以总耗时。缓存汇总以总缓存输入除以总输入；缓存写入单列，未命中读取缓存为输入减缓存读取。缺少有效数据或时长为零时显示 —。
