# statusx

直接打开并请求展开会话指标插件的原生面板。

1. 从可信的当前会话上下文取得 thread_id；若上下文没有提供，读取环境变量 CODEX_THREAD_ID。仅接受标准 UUID。不要列出会话后选择最近活跃的一条，也不要硬编码其他会话 ID。
2. 找到 codex-session-metrics 插件的 open_metrics 工具；必要时用宿主提供的工具发现功能加载它。传入当前会话的 thread_id 并调用。工具返回的 UI 即指标面板，不要用文本表格替代。
3. 若无法取得可靠的当前会话 ID，不传 thread_id 调用 open_metrics，让面板显示绑定表单；说明可从内置 /status 查询会话 ID 后绑定。
4. 调用成功后只需简短说明面板已打开。宿主可能以展开面板或聊天卡片展示，实际显示方式由宿主决定；不要声称已打开侧栏，除非得到对应结果。

该命令只负责唤起已有面板，不修改网关、配置或安装状态。工具不可用时，明确说明需要启用“会话指标”插件并重新加载 Codex，不要伪造实时指标。
